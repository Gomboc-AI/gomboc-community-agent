# GitHub Actions Integration

Automate security scanning and remediation in your CI/CD pipeline.

## Quick Start

### 1. Add GOMBOC_PAT Secret

Go to your repository:
- **Settings** → **Secrets and variables** → **Actions**
- **New repository secret**
- Name: `GOMBOC_PAT`
- Paste your token from [setup.md](setup.md)

### 2. Create Workflow File

Create `.github/workflows/gomboc-security.yml`:

```yaml
name: Gomboc Security Scan

on:
  pull_request:
  push:
    branches: [main, develop]
  schedule:
    # Run daily at 2 AM UTC
    - cron: "0 2 * * *"

jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Install dependencies
        run: |
          pip install requests pyyaml
      
      - name: Run Gomboc scan
        env:
          GOMBOC_PAT: ${{ secrets.GOMBOC_PAT }}
        run: |
          python scripts/cli-wrapper.py scan --path terraform/ --format json --output scan-results.json
      
      - name: Upload scan results
        uses: actions/upload-artifact@v3
        if: always()
        with:
          name: gomboc-scan-results
          path: scan-results.json
      
      - name: Comment on PR
        if: github.event_name == 'pull_request'
        run: |
          python scripts/comment-on-pr.py scan-results.json
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### 3. (Optional) Auto-Remediate

To automatically fix issues and create PRs:

```yaml
name: Gomboc Auto-Remediate

on:
  schedule:
    # Run daily
    - cron: "0 3 * * *"

jobs:
  remediate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
        with:
          fetch-depth: 0
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Run Gomboc fixes
        env:
          GOMBOC_PAT: ${{ secrets.GOMBOC_PAT }}
        run: |
          python scripts/cli-wrapper.py fix --path terraform/ --apply --format pull_request
      
      - name: Create Pull Request
        uses: peter-evans/create-pull-request@v5
        with:
          commit-message: "Security: Auto-remediate infrastructure issues"
          title: "🔒 Security: Gomboc auto-remediation"
          body: "Automated security fixes generated by Gomboc ORL Engine"
          branch: gomboc/auto-fix
          delete-branch: true
```

## Workflow Examples

### Example 1: Scan on PR with Comment

Scans only when PR is created, posts findings as comment:

```yaml
name: Security Check

on:
  pull_request:
    paths:
      - 'terraform/**'
      - 'cloudformation/**'

jobs:
  gomboc:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Scan with Gomboc
        id: scan
        env:
          GOMBOC_PAT: ${{ secrets.GOMBOC_PAT }}
        run: |
          python scripts/cli-wrapper.py scan \
            --path terraform/ \
            --format markdown \
            --output scan-report.md
      
      - name: Post comment
        if: always()
        uses: actions/github-script@v6
        with:
          script: |
            const fs = require('fs');
            const report = fs.readFileSync('scan-report.md', 'utf8');
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: report
            });
```

### Example 2: Fail Workflow on High-Severity Issues

Block merge if critical issues found:

```yaml
name: Security Gate

on: [pull_request]

jobs:
  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Scan with threshold
        env:
          GOMBOC_PAT: ${{ secrets.GOMBOC_PAT }}
        run: |
          python scripts/cli-wrapper.py scan \
            --path terraform/ \
            --fail-on-severity HIGH \
            --exit-code
```

Send daily security report email:

```yaml

on:
  schedule:
    - cron: "0 9 * * *"  # 9 AM daily

jobs:

          password: ${{ secrets.MAIL_PASS }}

          to: security-team@example.com
          html_body: file://digest.html
```

### Example 4: Multi-Environment Scans

Scan different configs per environment:

```yaml
name: Multi-Env Security Scan

on: [push]

jobs:
  scan:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        environment: [dev, staging, prod]
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Scan ${{ matrix.environment }}
        env:
          GOMBOC_PAT: ${{ secrets.GOMBOC_PAT }}
        run: |
          python scripts/cli-wrapper.py scan \
            --path terraform/${{ matrix.environment }}/ \
            --policy ${{ matrix.environment }}-policy \
            --output scan-${{ matrix.environment }}.json
      
      - name: Upload results
        uses: actions/upload-artifact@v3
        with:
          name: scan-results
          path: scan-*.json
```

## Helper Scripts

### `scripts/comment-on-pr.py`

Post scan results as PR comment:

```python
#!/usr/bin/env python3
import json
import os
import sys
import requests

def comment_on_pr(scan_file):
    with open(scan_file) as f:
        scan_result = json.load(f)
    
    # Format results
    comment = f"""## 🔒 Security Scan Results

**Total Issues:** {scan_result.get('issue_count', 0)}

"""
    
    by_severity = {}
    for issue in scan_result.get('issues', []):
        severity = issue.get('severity', 'UNKNOWN')
        if severity not in by_severity:
            by_severity[severity] = []
        by_severity[severity].append(issue)
    
    for severity in ['HIGH', 'MEDIUM', 'LOW']:
        if severity in by_severity:
            comment += f"\n### {severity} Severity\n"
            for issue in by_severity[severity]:
                comment += f"- **{issue['title']}** ({issue['file']}:{issue['line']})\n"
                comment += f"  {issue['description']}\n"
    
    # Post comment
    token = os.getenv('GITHUB_TOKEN')
    pr_number = os.getenv('GITHUB_PR_NUMBER')
    repo = os.getenv('GITHUB_REPOSITORY')
    
    if not all([token, pr_number, repo]):
        print("Missing GitHub env vars")
        return
    
    url = f"https://api.github.com/repos/{repo}/issues/{pr_number}/comments"
    headers = {
        'Authorization': f'token {token}',
        'Content-Type': 'application/json'
    }
    
    requests.post(url, json={'body': comment}, headers=headers)
    print(f"Posted comment on PR #{pr_number}")

if __name__ == '__main__':
    comment_on_pr(sys.argv[1])
```

### `scripts/generate-digest.py`

Create HTML digest of security findings:

```python
#!/usr/bin/env python3
import json
import subprocess
import os
from datetime import datetime

def generate_digest():
    # Run scan
    result = subprocess.run([
        'python', 'scripts/cli-wrapper.py', 'scan',
        '--path', '.',
        '--format', 'json',
        '--output', '/tmp/scan.json'
    ], env={'GOMBOC_PAT': os.getenv('GOMBOC_PAT')})
    
    with open('/tmp/scan.json') as f:
        scan = json.load(f)
    
    # Generate HTML
    html = f"""
    <html>
    <head>
        <style>
            body {{ font-family: Arial; }}
            .high {{ color: red; }}
            .medium {{ color: orange; }}
            .low {{ color: blue; }}
        </style>
    </head>
    <body>
        <h1>🔒 Security Digest - {datetime.now().strftime('%Y-%m-%d')}</h1>
        <p>Total Issues: <strong>{scan['issue_count']}</strong></p>
    """
    
    for issue in scan['issues']:
        severity_class = issue['severity'].lower()
        html += f"""
        <div class="{severity_class}">
            <h3>{issue['title']}</h3>
            <p>Severity: <strong>{issue['severity']}</strong></p>
            <p>File: <code>{issue['file']}</code></p>
            <p>{issue['description']}</p>
            <p>Fix: {issue['remediation']}</p>
        </div>
        """
    
    html += "</body></html>"
    print(html)

if __name__ == '__main__':
    generate_digest()
```

## Best Practices

### 1. **Separate Scan and Fix Jobs**
```yaml
# Good: Scan first, then decide on fixes
jobs:
  scan:
    # ...scans...
  fix:
    needs: scan
    if: needs.scan.outputs.issue_count > 0
    # ...applies fixes...

# Bad: Scanning and fixing in same job
jobs:
  all-in-one:
    # ...both...
```

### 2. **Use Branch Protection Rules**
In repo Settings → Branches → Add protection:
- Require status check for `security-scan` to pass
- Dismiss stale pull request approvals
- Require code review before merge

### 3. **Cache Scan Results**
```yaml
- uses: actions/cache@v3
  with:
    path: .gomboc-cache
    key: gomboc-${{ hashFiles('terraform/**') }}
```

### 4. **Run on Schedule + PR**
```yaml
on:
  pull_request:
  push:
    branches: [main]
  schedule:
    - cron: "0 2 * * *"  # 2 AM daily
```

### 5. **Set Exit Codes**
```bash
# Exit with 1 if HIGH issues found
python scripts/cli-wrapper.py scan \
  --path terraform/ \
  --fail-on-severity HIGH \
  --exit-code
```

## Troubleshooting

### Workflow Fails with "GOMBOC_PAT not found"

**Fix:** Ensure secret is added to repo settings
```bash
# Verify in GitHub UI
Settings → Secrets and variables → Actions
```

### Scan Takes Too Long

**Solution:** Limit scope
```yaml
- name: Scan
  run: |
    python scripts/cli-wrapper.py scan \
      --path terraform/ \
      --exclude-path vendor/**,**/.terraform/**
```

### Permission Denied on PR Comment

**Fix:** Ensure GITHUB_TOKEN is passed
```yaml
- uses: actions/github-script@v6
  with:
    github-token: ${{ secrets.GITHUB_TOKEN }}
```
