# MCP Integration Guide: Gomboc + OpenClaw Agents

Use Gomboc's MCP server to give agents real-time security scanning and code remediation capabilities.

## Overview

Gomboc exposes an MCP server (Model Context Protocol) that agents can interact with:

```
OpenClaw Agent
    ↓
  MCP Client
    ↓
Gomboc MCP Server (Docker)
    ↓
Gomboc ORL Engine
    ↓
Infrastructure Code
```

This allows agents to:
- Scan code for security issues
- Generate merge-ready fixes
- Apply remediations interactively
- Report findings in real-time

## Setup

### 1. Start the MCP Server

```bash
docker run -p 3100:3100 \
  -e GOMBOC_PAT='your-token-here' \
  gombocai/mcp:latest
```

Server runs on `http://localhost:3100`

### 2. Verify Server is Running

```bash
curl http://localhost:3100/health
# Response: {"status": "ok"}
```

## MCP Tools Available

The Gomboc MCP server exposes these tools to agents:

### `scan`

Scan infrastructure code for security issues.

**Parameters:**
- `path` (string, required): Path to scan (file or directory)
- `format` (string, optional): Output format (`json`, `markdown`, `sarif`) — default: `json`
- `policy` (string, optional): Policy to apply (`default`, `aws-cis`, etc.) — default: `default`

**Example:**
```json
{
  "tool": "gomboc.scan",
  "input": {
    "path": "./terraform/prod",
    "format": "json",
    "policy": "default"
  }
}
```

**Response:**
```json
{
  "scan_id": "scan_abc123",
  "path": "./terraform/prod",
  "issues": [
    {
      "id": "issue_1",
      "severity": "HIGH",
      "title": "S3 Bucket Missing Encryption",
      "description": "Bucket does not have encryption at rest configured",
      "file": "s3.tf",
      "line": 12,
      "remediation": "Add server_side_encryption_configuration block"
    }
  ],
  "issue_count": 5,
  "confidence": 0.94
}
```

### `fix`

Generate deterministic fixes for identified issues.

**Parameters:**
- `scan_id` (string, required): ID from previous scan
- `auto_apply` (boolean, optional): Apply fixes automatically — default: `false`
- `output_format` (string, optional): Format for fixes (`pull_request`, `patch`, `code`) — default: `pull_request`

**Example:**
```json
{
  "tool": "gomboc.fix",
  "input": {
    "scan_id": "scan_abc123",
    "auto_apply": false,
    "output_format": "pull_request"
  }
}
```

**Response:**
```json
{
  "fixes": [
    {
      "id": "fix_1",
      "issue_id": "issue_1",
      "title": "Enable S3 Encryption at Rest",
      "description": "Add server_side_encryption_configuration to s3.tf",
      "code": "resource \"aws_s3_bucket_server_side_encryption_configuration\" { ... }",
      "file": "s3.tf",
      "confidence": 0.96,
      "status": "ready_to_review"
    }
  ],
  "pull_request": {
    "url": "https://github.com/your-org/your-repo/pull/123",
    "title": "Security: Auto-remediate infrastructure issues",
    "description": "5 security fixes generated by Gomboc ORL Engine"
  }
}
```

### `remediate`

Apply fixes directly to code (one-shot operation).

**Parameters:**
- `path` (string, required): Path to remediate
- `fixes` (array, optional): Specific fix IDs to apply
- `commit` (boolean, optional): Auto-commit after fixing — default: `false`
- `push` (boolean, optional): Push to remote after commit — default: `false`

**Example:**
```json
{
  "tool": "gomboc.remediate",
  "input": {
    "path": "./terraform",
    "commit": true,
    "push": false
  }
}
```

## Agent Integration Patterns

### Pattern 1: Scan & Review

Agent scans code and reports findings to human for review:

```python
# Agent pseudocode
scan_result = mcp_call("gomboc.scan", {
    "path": "./terraform/prod",
    "policy": "aws-cis"
})

for issue in scan_result.issues:
    agent.report_to_human({
        "type": "security_finding",
        "severity": issue.severity,
        "title": issue.title,
        "file": issue.file,
        "remediation": issue.remediation
    })

# Wait for human approval before proceeding
```

### Pattern 2: Scan & Auto-Fix (with Review)

Agent scans, generates fixes, creates PR, waits for approval:

```python
# Step 1: Scan
scan = mcp_call("gomboc.scan", {"path": "./terraform"})

# Step 2: Generate fixes
fixes = mcp_call("gomboc.fix", {
    "scan_id": scan.id,
    "auto_apply": false,  # Don't apply yet
    "output_format": "pull_request"
})

# Step 3: Report to human
agent.request_approval({
    "type": "security_fix_approval",
    "pr_url": fixes.pull_request.url,
    "fixes_count": len(fixes.fixes),
    "description": "Generated security remediation PR. Review and merge if satisfied."
})

# Step 4: On approval, merge
if human_approved:
    merge_pull_request(fixes.pull_request.url)
```

### Pattern 3: Continuous Remediation

Agent continuously scans and auto-fixes on a schedule:

```python
# Runs on interval (e.g., hourly)
while True:
    # Scan
    scan = mcp_call("gomboc.scan", {"path": "./infrastructure"})
    
    if scan.issue_count > 0:
        # Auto-fix
        mcp_call("gomboc.remediate", {
            "path": "./infrastructure",
            "commit": true,
            "push": true
        })
        
        agent.log(f"Auto-remediated {scan.issue_count} issues")
    
    sleep(3600)  # Run hourly
```

### Pattern 4: Pre-Commit Hook

Agent checks code before commit:

```python
# On pre-commit event
scan = mcp_call("gomboc.scan", {"path": "."})

if scan.issue_count > 0:
    agent.block_commit({
        "message": f"Found {scan.issue_count} security issues. Fix with: gomboc-security fix",
        "issues": scan.issues
    })
else:
    agent.allow_commit()
```

## Configuration for Agents

### Via Environment Variables

```bash
export GOMBOC_MCP_URL="http://localhost:3100"
export GOMBOC_PAT="your-token-here"
export GOMBOC_POLICY="aws-cis"
export GOMBOC_AUTO_FIX="false"
```

### Via Config File (`.gomboc-agent.yml`)

```yaml
mcp:
  url: "http://localhost:3100"
  timeout: 30  # seconds

gomboc:
  pat: "${GOMBOC_PAT}"  # From env
  policy: "aws-cis"
  auto_fix: false
  
scan:
  paths:
    - "terraform/"
    - "cloudformation/"
  exclude:
    - "vendor/"
    - ".terraform/"

fix:
  output_format: "pull_request"
  create_branch: true
  branch_prefix: "gomboc/fix/"
```

## Error Handling

### "MCP Server not responding"

```python
try:
    scan = mcp_call("gomboc.scan", ...)
except ConnectionError:
    agent.log("Gomboc MCP server not available")
    # Fallback to local CLI or skip scanning
```

### "No fixes available"

```python
fixes = mcp_call("gomboc.fix", {"scan_id": scan.id})
if not fixes.fixes:
    agent.log("All issues are best-effort manual reviews")
```

### "Policy not found"

```python
# Verify available policies before scanning
scan = mcp_call("gomboc.scan", {
    "path": "./terraform",
    "policy": "aws-cis"  # May not exist
})

if scan.error == "policy_not_found":
    # Fallback to default policy
    scan = mcp_call("gomboc.scan", {"path": "./terraform"})
```

## Performance Tips

1. **Batch Scans:** Scan directories, not individual files
   ```python
   # Good
   mcp_call("gomboc.scan", {"path": "./terraform"})
   
   # Slow
   for file in glob("./terraform/**/*.tf"):
       mcp_call("gomboc.scan", {"path": file})
   ```

2. **Reuse Scan Results:** Generate multiple fix formats from one scan
   ```python
   scan = mcp_call("gomboc.scan", {"path": "."})
   
   json_fixes = mcp_call("gomboc.fix", {"scan_id": scan.id, "output_format": "json"})
   pr_fixes = mcp_call("gomboc.fix", {"scan_id": scan.id, "output_format": "pull_request"})
   ```

3. **Cache Results:** Store scan results for 1+ hours
   ```python
   if cache.has("scan_result_terraform") and cache.age() < 3600:
       scan = cache.get("scan_result_terraform")
   else:
       scan = mcp_call("gomboc.scan", {"path": "./terraform"})
       cache.set("scan_result_terraform", scan)
   ```

## Advanced: Custom Policies

Define custom security policies for your organization:

```yaml
# .gomboc/policies/custom-policy.yml
version: "1.0"
name: "my-org-security"
description: "Org-specific security standards"

rules:
  - id: "s3-encryption"
    severity: "HIGH"
    applies_to: ["aws_s3_bucket"]
    check: "has(server_side_encryption_configuration)"
    fix: "add_encryption_configuration()"
  
  - id: "sg-no-0-0-0-0"
    severity: "HIGH"
    applies_to: ["aws_security_group"]
    check: "no_cidr_blocks(['0.0.0.0/0'])"
    fix: "restrict_to_internal_cidrs()"
```

Apply custom policy:
```python
mcp_call("gomboc.scan", {
    "path": "./terraform",
    "policy": "custom-policy"
})
```
