USAGE QUICK START
================================================================================

1. AUTHENTICATION (2 minutes)
   - Visit app.gomboc.ai and sign up (free, no credit card)
   - Generate Personal Access Token
   - Set: export GOMBOC_PAT="your-token"

2. START MCP SERVER (1 minute)
   cd scripts
   docker-compose up -d
   
3. VERIFY SETUP (1 minute)
   curl http://localhost:3100/health
   bash scripts/verify-setup.sh

4. TEST SCAN (1 minute)
   python scripts/cli-wrapper.py scan --path examples/ --format markdown

5. GENERATE FIXES (1 minute)
   python scripts/cli-wrapper.py fix --path examples/

TOTAL TIME: ~5 minutes to production-ready

INTEGRATION PATTERNS
================================================================================

PATTERN 1: AGENTS (Interactive)
───────────────────────────────
agent.use_mcp_tool("gomboc", "scan", {"path": "./terraform"})
agent.use_mcp_tool("gomboc", "fix", {"scan_id": "...", "auto_apply": false})
agent.request_approval(fixes)

PATTERN 2: DEVELOPERS (Local)
─────────────────────────────
gomboc-security scan --path . --fail-on-severity HIGH
gomboc-security fix --path . --apply

PATTERN 3: CI/CD (Automated)
────────────────────────────
- uses: GitHub workflow
  env:
    GOMBOC_PAT: ${{ secrets.GOMBOC_PAT }}
  run: gomboc-security scan --path terraform/
